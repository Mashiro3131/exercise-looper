# Snapshots

Currently made manually.

## Why

-   Snapshots provide a quick restore point before making changes (e.g.,
    updates, configuration changes, testing).
-   They allow fast recovery in case of misconfiguration, failed
    updates, or other issues.
-   Used mainly as a safety net rather than a full backup solution.

## How

-   Log in to the Proxmox web UI.
-   Select the VM or container.
-   Navigate to the **Snapshots** tab.
-   Click **Take Snapshot**, provide a name/description, and confirm.
-   Restore or roll back by selecting the snapshot in the same tab and
    choosing the appropriate action.
